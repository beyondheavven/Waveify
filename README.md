  <b>Waveify</b> — современный музыкальный плеер для Android, объединяющий треки из <b>Spotify</b> и <b>SoundCloud</b> в едином стильном интерфейсе с уникальным рендерингом обложек в стиле <b>ASCII-арт</b>.
</p>

---

## ✨ Ключевые особенности

- 🔀 **Мультиплатформенность стриминга**: Поддержка каталогов и воспроизведения из **Spotify** и **SoundCloud**.
- 📟 **ASCII Art Cover Engine**:
  - Динамическая конвертация обложек альбомов в цветной или стилизованный ASCII-арт на лету.
  - Режимы палитры: **Full Color**, **Waveify Neon Red**, **Matrix CRT Green**, **Monochrome** и классический оригинальный вид.
  - Кастомная трансформация Coil с аппаратным ускорением на `Canvas` и автоматическим LRU-кэшированием в RAM.
- 🎵 **Продвинутый аудиоплеер**:
  - Полноэкранный плеер с таймлайном и модальным управлением.
  - Интерактивный мини-плеер с плавными анимациями появления.
  - Фоновое воспроизведение на базе **AndroidX Media3 (ExoPlayer)** с поддержкой HLS.
- 🎨 **Современный UI**:
  - Полностью на **Jetpack Compose** и **Material 3**.
  - Глубокая неоновая темная тема (`#0D0D11`, акцент `#FF2A54`).
  - Профиль с авторизацией в Spotify и привязкой аккаунта SoundCloud.

---

## 🛠️ Стек технологий

| Технология | Назначение |
|---|---|
| **Kotlin** | Основной язык разработки (Coroutines, Flow) |
| **Jetpack Compose & Material 3** | Декларативный UI |
| **AndroidX Media3 / ExoPlayer** | Воспроизведение аудиопотоков и HLS |
| **Coil Compose** | Загрузка изображений и кастомный ASCII Transformation |
| **Retrofit 2 & OkHttp 3** | Сетевые запросы к REST API |
| **Gson** | Сериализация JSON |
| **Spotify Android SDK** | Авторизация и интеграция Spotify |
